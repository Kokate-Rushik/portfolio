Domain-Aware Library Search Engine

College RAG Project

An intelligent search and recommendation tool built for university students to easily find academic materials. Instead of exact title matches, it uses AI and Natural Language Processing (NLP) to understand the meaning behind a student's search query.

How I Built It

Traditional systems fail when search words don't exactly match book titles. I solved this by converting book descriptions into numerical embeddings using `nomic-embed-text` and storing them in ChromaDB. To handle broad or vague searches, I layered a custom "Subject Map" classification step using a local LLM. This identifies the topic first before searching the database, keeping results accurate and API costs at zero.
